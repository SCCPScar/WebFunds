# WebFunds

> Your personal financial operating system.

## Overview

WebFunds is a private, AI-assisted personal finance application built exclusively for its owner.

Its goal is not only to track expenses, but to create complete financial awareness through intelligent organization, banking synchronization, budgeting, financial cycles and contextual memory.

The application is designed with:

- Flutter
- Supabase
- PostgreSQL
- Drift (SQLite)
- Riverpod
- Anthropic Claude
- OpenAI
- Millennium BCP (Open Banking / PSD2)

---

## Project Goals

- Complete control of personal finances
- Offline-first
- AI-assisted organization
- Automatic bank synchronization
- Beautiful, modern interface
- Spider-Man inspired visual identity
- Enterprise-grade architecture
