# Product Language

> Consistency creates confidence.

---

# Purpose

This document defines the official language used throughout WebFunds.

Every screen, button, notification, dialog, AI response and error message must follow these rules.

Users should always feel that the application speaks with a single voice.

---

# Language Principles

WebFunds communicates using language that is:

- Clear
- Calm
- Friendly
- Professional
- Direct
- Human

The application never sounds robotic or overly corporate.

---

# Official Product Terminology

The following names are mandatory.

| Concept | Official Name |
|----------|---------------|
| Home Screen | Central |
| AI Assistant | Weaver |
| Savings Area | Vault |
| Unknown Transactions | Mysteries |
| Financial Period | Financial Cycle |
| User Notes | Memories |
| User | Owner |

Never replace these names with alternatives.

---

# Navigation Labels

Use short and recognizable labels.

Preferred:

- Central
- Finances
- Vault
- Mysteries
- Weaver
- Profile

Avoid long menu names.

---

# Button Labels

Buttons should begin with an action.

Examples:

- Add Transaction
- Add Memory
- Review
- Continue
- Save
- Cancel
- Connect Bank
- Start Financial Cycle
- Attach Receipt

Avoid generic labels such as:

- Submit
- Confirm
- Execute
- Process

---

# Dialog Titles

Dialog titles should explain the purpose immediately.

Good:

Start a Financial Cycle

Review Transaction

Delete Memory

Connect Your Bank

Bad:

Confirmation

Attention

Action Required

---

# Empty States

Always explain what the user can do next.

Instead of:

No transactions.

Use:

Your imported transactions will appear here.

Connect your bank or add one manually.

---

# Error Messages

Every error must answer:

- What happened?
- Why?
- What can I do now?

Example

We couldn't connect to your bank.

Please try again in a few minutes.

Avoid:

Unknown error.

Operation failed.

Unexpected exception.

---

# Success Messages

Success messages should be short.

Examples

Transaction saved.

Receipt attached.

Memory added.

Financial Cycle started.

Bank connected.

Avoid unnecessary celebration.

---

# Notifications

Notifications should feel informative.

Good examples

Three new transactions are ready for review.

Your bank sync has finished.

We found a possible subscription.

Avoid

Warning!

Attention!

Urgent!

Unless the situation is genuinely critical.

---

# Confirmation Dialogs

Confirm only important actions.

Examples

Delete transaction

Disconnect bank

Delete Financial Cycle

Delete Memory

Never ask confirmation for simple actions like opening a screen.

---

# Financial Language

Money is neutral.

Never shame the owner.

Bad

You spent too much.

Good

Your spending in Restaurants is above your usual average.

---

# AI Language

Weaver speaks naturally.

Weaver never pretends certainty.

Preferred

"I believe this transaction belongs to Groceries."

"I found a possible match."

"This looks similar to previous purchases."

Avoid

"This is definitely..."

"This is wrong."

"You should..."

---

# Dates

Always display dates using the owner's locale.

Examples

19 Jul 2026

Today

Yesterday

Avoid technical date formats unless exporting data.

---

# Currency

Always display currency using the owner's locale.

Examples

€1,250.00

€32.49

Never separate the currency symbol from the amount.

---

# Categories

Categories should always use singular nouns.

Correct

Restaurant

Transport

Salary

Gift

Health

Subscription

Incorrect

Restaurants

Transportations

Salaries

---

# Capitalization

Use Sentence case.

Correct

Start Financial Cycle

Connect your bank

Review transaction

Avoid

START FINANCIAL CYCLE

start financial cycle

---

# Technical Language

Never expose implementation details.

Avoid terms such as:

API

Database

JSON

Cache

Token

HTTP

Server

Unless the owner is explicitly viewing developer information.

---

# Destructive Actions

Use clear language.

Preferred

Delete Transaction

Disconnect Bank

Delete Memory

Avoid euphemisms.

The owner should always know exactly what will happen.

---

# Weaver Personality Summary

Weaver should always sound:

- Calm
- Curious
- Helpful
- Honest
- Respectful
- Intelligent

Never sarcastic.

Never dramatic.

Never judgmental.

---

# Final Principle

Every sentence inside WebFunds should help the owner understand their finances with less effort.

If a simpler sentence exists,

use it.
