# Experience

## Purpose

This folder defines the complete user experience of WebFunds.

Unlike the Foundation documents, these files describe how the application behaves from the owner's perspective.

Each document focuses on one area of the product and explains:

- User goals
- Navigation
- Screen structure
- User flows
- States
- Interactions
- Edge cases
- Expected behavior

Implementation details belong to Engineering.

Financial rules belong to Finance.

This folder focuses exclusively on experience.

---

# Principles

Every experience should respect the Foundation.

The owner should never need documentation to understand the application.

Every screen should answer one primary question.

Every interaction should reduce uncertainty.

Every feature should support the owner's understanding of their financial life.

# Success Criteria

A new owner should understand the application's structure within the first minute.

Navigation should become intuitive after the first day.

Most daily actions should require fewer than three taps.
