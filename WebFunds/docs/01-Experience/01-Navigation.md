# Navigation

> Navigation should feel invisible.

---

# Philosophy

The owner should always know:

- Where they are.
- Where they came from.
- Where they can go next.

Navigation should never require thinking.

---

# Mobile Navigation

Primary navigation uses a Bottom Navigation Bar.

Items:

Central

Finances

Vault

Mysteries

Weaver

The Profile screen is accessed from the avatar located in the top-right corner.

---

# Desktop Navigation

Desktop uses a left Sidebar.

Sections remain identical.

No features should exist only on desktop.

---

# Navigation Rules

The current page is always highlighted.

Navigation labels never change.

Icons remain consistent.

Badges should only appear when attention is required.

---

# Navigation Hierarchy

Level 1

Bottom Navigation

↓

Level 2

Screen

↓

Level 3

Details

↓

Level 4

Dialogs

---

# Back Navigation

Always returns to the previous context.

Never to the Home screen unless explicitly requested.

---

# Deep Links

The application should support opening directly into:

A transaction

A Memory

A Financial Cycle

A Vault Goal

A Mystery

A Weaver conversation

---

# Gestures

iPhone gestures should follow native behavior.

Swipe back.

Pull to refresh.

Long press for contextual actions.

Swipe on transaction cards for quick actions.

---

# Quick Actions

Long press on the app icon should expose:

Add Transaction

Search

Open Weaver

Scan Receipt

---

# Future Expansion

Additional modules should never increase the number of Bottom Navigation items.

Five primary destinations are the maximum.

Future features should integrate into existing sections.

---

# Final Principle

The owner should always know where to go next without searching for it.
