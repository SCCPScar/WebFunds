# Mysteries

> Every unknown transaction deserves an explanation.

---

# Purpose

Mysteries is a dedicated workspace for transactions that require additional context before they become part of the owner's financial story.

Unlike a bank statement, WebFunds does not assume that imported data is complete.

Mysteries helps transform unknown transactions into meaningful memories.

---

# Philosophy

A transaction is not complete until the owner understands it.

Unknown transactions should never disappear inside a long transaction list.

They deserve attention.

---

# What Is a Mystery?

A Mystery is any transaction that:

- has an unknown merchant
- has no category
- contains unclear bank information
- was imported with low AI confidence
- has no Memory attached
- was manually marked by the owner

A transaction may remain a Mystery for as long as necessary.

---

# Primary Goals

The owner should be able to:

• Review unknown transactions

• Add context

• Confirm AI suggestions

• Attach receipts

• Create Memories

• Resolve Mysteries

The owner may manually create a Mystery even for a known transaction.

Example:

"I remember buying something here but I don't remember what."
