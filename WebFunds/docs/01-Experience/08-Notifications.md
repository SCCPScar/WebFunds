# Notifications

> Inform without interrupting.

---

# Purpose

Notifications keep the owner informed about important financial events without creating stress or anxiety.

Every notification should have a clear purpose.

If a notification does not help the owner make a better financial decision, it should not exist.

---

# Philosophy

Notifications should feel like a quiet assistant.

Not an alarm.

WebFunds communicates only when there is value.

Silence is preferred over unnecessary interruptions.

---

# Notification Types

The application supports:

• Push Notifications

• In-App Notifications

• Notification Center

• Badge Counters

Each serves a different purpose.

---

# Notification Center

The Notification Center stores recent events.

Each notification contains:

Title

Description

Timestamp

Category

Priority

Related Action

Notifications remain available until dismissed or archived.

# Priority Levels

Low

General information.

Medium

Requires attention soon.

High

Requires owner review.

Critical

Security-related events only.

Critical notifications are extremely rare.

---

# Bank Notifications

Examples:

Bank synchronization completed.

New account connected.

Connection lost.

Multiple transactions imported.

Synchronization failed.

---

# Mystery Notifications

Examples:

Three transactions need review.

A Mystery has been unresolved for seven days.

A new unknown merchant was detected.

---

# Dream Notifications

Examples:

You reached 50% of your Travel Dream.

A Dream was completed.

A scheduled contribution was skipped.

---

# Financial Cycle Notifications

Examples:

Income detected.

A new Financial Cycle may be appropriate.

Current Financial Cycle is approaching its usual duration.

The owner always confirms cycle changes.

---

# Weaver Notifications

Examples:

I found a recurring subscription.

This expense is unusual.

Your grocery spending is below average this cycle.

You may safely reserve money for your Travel Dream.

Weaver notifications should never feel alarming.

---

# Security Notifications

Examples:

New device connected.

Face ID disabled.

Bank access revoked.

Multiple failed login attempts.

Security notifications always use High or Critical priority.

---

# System Notifications

Examples:

Backup completed.

Update available.

Import completed.

Export finished.

---

# Notification Actions

---

# Smart Grouping

Notifications should be grouped whenever possible.

Example:

Instead of:

Five transaction notifications.

Display:

Five new transactions imported.

---

# Quiet Hours

The owner may configure Quiet Hours.

During Quiet Hours:

Only Critical notifications are delivered immediately.

Everything else waits.
