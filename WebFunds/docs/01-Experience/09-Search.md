# Search

> Everything should be one search away.

---

# Purpose

Search provides a unified way to access any relevant information inside WebFunds.

The owner should never need to remember where information is stored.

Search should understand intent, not only keywords.

---

# Philosophy

Search is global.

Every important object inside WebFunds should be searchable.

Search exists to reduce effort.

Not to expose database structure.

# Performance

Search begins after 250ms.

Results appear progressively.

Most recent matches appear first.

Search should feel instantaneous.

---

# Offline

Previously indexed information remains searchable.

Cloud-only information becomes unavailable.
