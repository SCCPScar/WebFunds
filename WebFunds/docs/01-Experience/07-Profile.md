# Profile

> Your financial control center.

---

# Purpose

The Profile screen centralizes the owner's personal settings, connected services, security preferences and application customization.

Unlike traditional settings pages, Profile should present information in a structured and approachable way.

The owner should immediately understand the current status of the application.

---

# Philosophy

Profile is not just a settings page.

It is the owner's control center.

Everything related to identity, security, banking and personalization starts here.
