# Onboarding

> The beginning of your financial story.

---

# Purpose

The onboarding experience introduces the owner to WebFunds and prepares the application for its first Financial Cycle.

It should be completed in less than five minutes.

The experience should feel calm, welcoming and transparent.

The owner should always understand why each permission or piece of information is requested.

---

# Philosophy

WebFunds does not ask for unnecessary information.

Every step has a purpose.

The owner remains in control at all times.

# Introduction

Explain:

WebFunds helps understand money.

It does not control bank accounts.

It never moves money.

It only analyzes financial information.

---

# Security

Explain:

Local encryption

Face ID support

Passcode protection

Secure storage

Owner confirms security settings.

---

# Connect Bank

The owner chooses a supported bank.

The application explains:

Read-only access

Synchronization

Privacy

No money movement

Primary Action:

Connect Bank

Secondary Action:

Skip for now

---

# Account Review

After connection:

Display all detected accounts.

The owner selects:

Accounts to import

Accounts to ignore

Hidden accounts remain available later.

---

# Initial Synchronization

Display progress.

Explain what is happening.

Possible steps:

Connecting

Importing accounts

Importing transactions

Analyzing merchants

Preparing Mysteries

Preparing Weaver

Preparing Financial Cycles

# Weaver Introduction

Explain:

Weaver suggests.

Weaver learns.

Weaver never acts automatically.

Provide example questions.

---

# Initial Scan

Weaver performs a first analysis.

Possible findings:

Unknown merchants

Possible subscriptions

Potential salary transactions

Duplicate merchants

Recurring expenses

Nothing is changed automatically.

# Finish

---

# Permissions

Only request permissions when needed.

Examples:

Camera

When scanning receipts.

Notifications

When enabling alerts.

Location

Only for future optional features.

Never request unnecessary permissions.

---

# Empty Import

If no transactions are available:

Explain that WebFunds becomes more useful over time.

Encourage manual transactions.

---

# Error Handling

If bank connection fails:

Explain the problem.

Allow retry.

Allow skipping.

Never block the owner.

---

# Offline

If connectivity is unavailable:

Allow local setup.

Bank connection waits until online.

---

# Success Criteria

The owner should understand:

How WebFunds works.

How Weaver behaves.

Why permissions are requested.

How Financial Cycles work.

The onboarding should create confidence rather than excitement.

---

# Final Principle

The owner's first five minutes define the trust relationship with WebFunds.
