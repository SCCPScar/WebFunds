Política de Privacidade — WebFunds

Última atualização: 1 de agosto de 2026

O WebFunds é uma aplicação pessoal de gestão financeira. Não é um produto comercial nem recolhe dados para fins de negócio — existe para ajudar o seu titular a organizar as suas próprias finanças.

Que dados são guardados

Consoante o que usa na aplicação, podem ser guardados:

  • Contas, ciclos financeiros, transações e objetivos de poupança que introduz manualmente;
  • Memórias e notas associadas a transações;
  • Preferências (aparência, notificações);
  • Se ligar uma conta bancária via Open Banking: informação de contas, saldos e transações fornecida pelo seu banco, apenas em modo de leitura.

Onde ficam guardados

A maior parte dos dados fica guardada localmente, no dispositivo ou navegador onde a aplicação é usada, numa base de dados local. Não existe um servidor central que armazene o histórico financeiro.

Com quem os dados são partilhados

  • Supabase — usado apenas para autenticação (email/palavra-passe) e sessão. Não recebe as suas transações ou saldos.
  • Anthropic (via função servidor própria) — quando o Weaver sugere uma categoria para uma transação, o texto dessa transação é enviado a um modelo de linguagem para gerar a sugestão. Nenhum outro dado é enviado.
  • Fornecedor de Open Banking (Enable Banking) — apenas se optar por ligar uma conta bancária. O acesso é sempre só de leitura: a aplicação nunca pode mover dinheiro, criar pagamentos ou alterar dados na sua conta bancária. Pode revogar este acesso a qualquer momento, junto do seu banco ou do fornecedor de Open Banking.

O que NÃO fazemos

  • Não mostramos anúncios;
  • Não vendemos nem partilhamos dados com terceiros para fins de marketing;
  • Não usamos ferramentas de analytics ou rastreamento de comportamento de terceiros.

Os seus direitos

Pode terminar a sessão, apagar os dados guardados localmente a qualquer momento, e revogar o acesso a qualquer conta bancária ligada diretamente junto do seu banco ou do fornecedor de Open Banking.
